AI PM Learning Path: 7-Week Curriculum

A comprehensive 7-week curriculum designed for Product Managers to master AI Agents, LLM Architecture, RAG, System Prompts, and Agentic Product Development.

WEEK 01

AI Fundamentals & LLM Architecture for PMs

Understand how Large Language Models work under the hood, tokenization, context windows, and model latency vs. cost tradeoffs.

  • Core Concepts: Neural Networks, Transformers, Attention Mechanism, Tokens vs. Words.
  • PM Tradeoffs: Cost per 1M tokens, Latency (TTFT - Time To First Token), and Context Window limits.
  • Hands-On: Tokenizer calculation exercises using OpenAI & Anthropic API calculators.
💡 Key Action Item: Map out an AI product feature latency budget (TTFT < 800ms) and cost per user query.
WEEK 02

Prompt Engineering, System Prompts & Context Management

Master zero-shot, few-shot prompting, system instructions, structured output formatting (JSON/Function calling), and prompt injections.

  • Techniques: Chain-of-Thought (CoT), Few-Shot examples, Role Prompting, and Negative Constraints.
  • Structured Outputs: Forcing JSON schemas, tool function calling definitions.
  • Security: Defending against prompt injection, jailbreaks, and data leakage.
💡 Key Action Item: Draft a robust System Prompt with fallback rules for edge cases and JSON schema constraints.
WEEK 03

AI Agents & Agentic Workflows (ReAct, Tools & Planning)

Dive into autonomous agents, the ReAct (Reason + Act) loop, tool calling APIs, multi-agent collaboration, and memory systems.

  • Agent Architecture: Perception, Reasoning, Planning, Tool Execution, and Memory (Short-term vs. Long-term).
  • Patterns: Router pattern, Evaluator-Optimizer loop, Parallel worker agents.
  • PM Metrics: Completion rate, loop count limits, retry budgets, and cost governance.
💡 Key Action Item: Design a flowchart for a customer support agent with tool calling access (Order API, Refund API).
WEEK 04

RAG (Retrieval-Augmented Generation) & Vector Databases

Learn how to ground AI models with internal company documentation, embeddings, vector search, and hybrid retrieval.

  • RAG Pipeline: Document Ingestion, Chunking Strategies, Embedding Generation, Vector Search.
  • Vector DBs: Pinecone, Milvus, Qdrant, PGVector — Indexing & Cosine Similarity.
  • Advanced RAG: Hybrid search (BM25 + Semantic), Re-ranking (Cohere Rerank), Query Rewriting.
💡 Key Action Item: Evaluate chunking strategies (256 vs 512 tokens) and retrieval recall accuracy on a sample dataset.
WEEK 05

Fine-Tuning vs. RAG & AI Model Evaluations (Evals)

Decide when to use Fine-Tuning vs. RAG, and set up continuous evaluation pipelines (Evals) to measure model quality.

  • Fine-Tuning: LoRA, QLoRA, Dataset preparation, Style vs. Knowledge injection.
  • LLM Evals: Automated LLM-as-a-Judge, Ground Truth benchmarks, Faithfulness & Relevancy scores.
  • PM Framework: Establishing a golden evaluation dataset for regression testing during model upgrades.
💡 Key Action Item: Build a 50-test-case Evaluation Matrix to benchmark GPT-4o vs Claude 3.5 Sonnet on core product prompts.
WEEK 06

Building Agentic Products: UX Patterns, Fallbacks & Safety

Master user experience design for probabilistic AI systems, handling streaming responses, human-in-the-loop, and guardrails.

  • UX Design: Streaming text, skeleton loaders, optimistic UI updates, error recovery states.
  • Safety Guardrails: NeMo Guardrails, Llama Guard, Content moderation APIs, PII redaction.
  • Human-in-the-Loop (HITL): Approval workflows for high-stakes actions (financial transfers, external emails).
💡 Key Action Item: Design wireframes for an AI assistant showing thought steps, source citations, and human approval buttons.
WEEK 07

Capstone Project & AI Product Lifecycle Management

Synthesize everything learned into a complete PRD (Product Requirements Document) for an agentic AI product release.

  • PRD Creation: Defining metrics (CSAT, Resolution rate, Cost/query, Fallback rate).
  • Architecture Specs: Model choice, RAG pipeline, Tool integrations, Safety layers.
  • Go-To-Market & Monitoring: Telemetry, cost alerts, drift detection, and continuous eval loops.
💡 Final Capstone Deliverable: Full Technical PRD for an Enterprise AI Agent with latency budget, safety rules, and ROI analysis.
